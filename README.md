使用champ开源算法,实现智元机器狗d1的ign-gazebo仿真
===
## 使用方式
- ign_gazebo节点
```
ros2 launch sim_ign_dog d1_gazebo_sim_dog.launch.py 
```
- 控制节点
```
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```
